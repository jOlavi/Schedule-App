# Schedule App

This app is made to handle your everyday todos. You can make new todos and give them categories and priorities to make your workflow more efficient. The app includes a calendar where you can see and plan your upcoming weeks.

You also have access to a plain ideas section where you can write down your ideas and save them for the future.

## TechStack

-   Next.js
-   TypeScript
-   PostgreSQL
-   Docker
-   Tailwind CSS

## Getting Started

After cloning the app, install all needed packages:

```
npm install
```

To run the app, you need to set up a Docker container for your database.  
Make sure Docker is installed and running.

Add a `.env` file to your project root with your own information:

```
DB_USER=
DB_PASSWORD=
DB_HOST=
DB_PORT=
DB_NAME=
```

After you have the database set up, you can start the app:

```
npm run dev
```
